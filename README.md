# ICCPDC 1977 — public site

**→ https://motomateo.github.io/iccpdc-site/**

This is the static site for the digitised ICCPDC synthesis (1978) on the 4 March 1977 earthquake. It has:
- **[Explorer](https://motomateo.github.io/iccpdc-site/explorer/)**: the argument flow, a topic network, statistics, the full text with page scans, a building index and the Part IV photos.
- **[Map](https://motomateo.github.io/iccpdc-site/map/)**: buildings and places from the text, county damage, today's footprints and photo galleries.
- **[Consolidări reduse](https://motomateo.github.io/iccpdc-site/explorer/#simplification)**: a dossier on strengthening projects reduced to local repairs in 1977.

**This repository is generated. Do not edit it by hand.** It is built from the source repository with
`scripts/build_site.py` and published with `scripts/deploy_site.py`. Each commit message names the source commit, and
`build_info.json` and `site_manifest.csv` (sha256 of every file) record exactly what was published.
